# 🌐 ترجمان AI (Turjuman AI) — المترجم الفوري الصوتي للاجتماعات والمؤتمرات

نظام ذكي متكامل مصمم خصيصاً لحل مشكلة حضور اجتماعات **زوم (Zoom)** والمؤتمرات باللغة الإنجليزية:
عندما يتحدث الضيف بالإنجليزية، يقوم النظام فورياً بتحويل صوته إلى **كلام عربي مكتوب ومنطوق (صوتياً)** أولاً بأول!

---

## 🌟 الميزات الأساسية

1. **📱 تطبيق ويب متجاوب (Mobile-First PWA)**:
   - يعمل على أي جهاز (آيفون، أندرويد، أو لابتوب) دون الحاجة لتثبيت أي تطبيقات معقدة.
   - يمكن إضافته للشاشة الرئيسية للهاتف (Add to Home Screen) ليعمل كتطبيق أصيل كامل الشاشة.

2. **🔊 ترجمة صوتية فورية متزامنة (Simultaneous Audio Interpretation)**:
   - لا يكتفي بعرض الترجمة كنص، بل ينطق الترجمة العربية بصوت واضح عبر سماعات الأذن أو سبيكر الموبايل أثناء حديث الضيف!

3. **🤖 ذكاء اصطناعي مزدوج (Dual Engine)**:
   - **Google Gemini AI**: ترجمة احترافية تفهم سياق الاجتماعات ومصطلحات الأعمال بدقة فائقة.
   - **المحرك العصبي الفوري (Instant Engine)**: سرعة استجابة فائقة (< 100ms) ومجاني 100% ويعمل فوراً بدون الحاجة لمفاتيح API.

4. **👥 وضع الغرف والمشاركة (Meeting Room Mode)**:
   - يمكنك تشغيل النظام على اللابتوب ومشاركة الرابط أو كود الـ **QR Code** مع العميل.
   - العميل يفتح الرابط على هاتفه ويستمع ويقرأ الترجمة الفورية المتزامنة في نفس اللحظة!

5. **📝 سجل المحادثات (Transcript History)**:
   - حفظ كامل لما قيل بالإنجليزية وترجمته بالعربية مع التوقيت، مع إمكانية نسخه كاملاً أو تنزيله كملف نصي.

6. **🧩 إضافة كروم المرفقة (Chrome Extension)**:
   - داخل مجلد `extension/` ستجد أيضاً إضافة كروم كاملة تدعم النافذة العائمة Always-on-Top (Picture-in-Picture) فوق برنامج زوم الديسكتوب.

## 🚀 التشغيل السريع على جهازك المحلي

```bash
# 1. التثبيت
npm install

# 2. التشغيل
npm start
```

افتح المتصفح على: `http://localhost:3000` (أو افتح عنوان الآي بي المحلي من هاتفك على نفس شبكة الواي فاي).

## ☁️ كيفية نشر التطبيق أونلاين (Deploy) في دقيقتين مجاناً

### الخيار 1: النشر على Render.com (الأسهل والأفضل لدعم WebSockets)
1. ارفع المشروع إلى حسابك في **GitHub**.
2. ادخل على [Render.com](https://render.com) واضغط **New Web Service**.
3. اربط مستودع GitHub، وسيتم التعرف تلقائياً على ملف `render.yaml`:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
4. (اختياري) أضف في Environment Variables:
   - `GEMINI_API_KEY`: مفتاح Gemini الخاص بك إن أردت تفعيل الذكاء الاصطناعي الأقصى (وإن لم تضعه سيعمل المحرك الفوري المجاني تلقائياً).
5. اضغط **Deploy Web Service** وستحصل على رابط أونلاين مباشر (مثال: `https://turjuman-ai.onrender.com`).

### الخيار 2: النشر عبر Docker أو أي سيرفر VPS
الملف `Dockerfile` مجهز وجاهز:
```bash
docker build -t turjuman-ai .
docker run -p 3000:3000 turjuman-ai
```

## 📱 كيف يستخدمه العميل على الموبايل؟

1. **السيناريو الأول (الموبايل بجانب اللابتوب)**:
   - يفتح العميل الرابط على متصفح هاتفه (سفاري على آيفون أو كروم على أندرويد).
   - يضغط على زر **«🎙️ بدء الاستماع والترجمة»**.
   - يضع الهاتف بجانب سماعات اللابتوب أو يرتدي سماعات الأذن.
   - بمجرد تحدث الضيف بالإنجليزية في زوم، تظهر الترجمة العربية فورياً على شاشة الهاتف، ويسمع صوتاً عربياً واضحاً ينطق الترجمة في أذنه أولاً بأول!

2. **السيناريو الثاني (مشاركة الغرفة)**:
   - أنت تفتح التطبيق على كمبيوترك وتضغط على **«مشاركة الغرفة»**.
   - يظهر لك رمز **QR Code** ورابط مخصص.
   - يقوم العميل بمسح الكود بكاميرا هاتفه للدخول للغرفة.
   - كل ما يُلتقط ويُترجم من اللابتوب يصل فورياً إلى هاتف العميل صوتياً وكتابياً!

## 🛠️ تثبيت إضافة كروم (إن أردت استخدامها داخل المتصفح)

إذا أردت استخدام الإضافة داخل متصفح كروم مباشرة:
1. افتح كروم واذهب إلى: `chrome://extensions/`
2. فعّل **Developer mode** من الزاوية العلوية.
3. اضغط **Load unpacked**.
4. اختر مجلد `extension` الموجود داخل هذا المشروع.
