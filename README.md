# ترجمان AI

تطبيق ويب يعرض الكلام الإنجليزي بالعربية ويقرأ ترجمته صوتياً. يشمل مشاركة الترجمة بين الأجهزة وإضافة Chrome لالتقاط تسميات الفيديو والاجتماعات.

## التشغيل

```bash
npm ci
npm start
```

افتح `http://localhost:3000`. يمكن تغيير المنفذ باستخدام `PORT`. لتشغيل Gemini ضع `GEMINI_API_KEY` في البيئة أو أدخل مفتاحك من الإعدادات. النموذج الافتراضي `gemini-2.5-flash` ويمكن تغييره بمتغير `GEMINI_MODEL`.

## الاستخدام

1. افتح التطبيق في متصفح يدعم التعرف على الكلام، واسمح بالوصول للميكروفون.
2. اضغط «بدء الاستماع والترجمة». النص الأولي يتحدث أثناء الكلام، والصوت يقرأ كل عبارة مكتملة مرة واحدة.
3. استخدم سماعات الأذن حتى لا يرجع صوت الترجمة إلى الميكروفون.
4. زر الصوت يكتم النطق أو يشغله. إذا منع الهاتف التشغيل التلقائي، أعد تشغيل الصوت من الزر.
5. افتح الإعدادات لتغيير المحرك والسرعة واللهجة وحجم الخط، أو فتح السجل أو مسح الشاشة أو مشاركة الغرفة.

الشاشة الرئيسية تحتوي ثلاثة أزرار: الاستماع، الصوت، والإعدادات. بقية المساحة مخصصة للقراءة. يحتفظ السجل بآخر 150 عبارة على الجهاز، وتعرض الشاشة آخر 300 مقطع.

## مشاركة الغرفة

من الإعدادات اختر «مشاركة الغرفة»، وافتح الرابط على الجهاز الآخر. شغّل المايك على جهاز التقاط الكلام فقط؛ الجهاز الآخر يستقبل الترجمة بدون تشغيل المايك.

ينشئ التطبيق غرفة عشوائية عند فتح الصفحة الرئيسية ويتذكرها على الجهاز. روابط الغرف القديمة تبقى صالحة. أي شخص يملك رابط الغرفة يستطيع استقبالها والبث إليها؛ الغرف لا تتضمن تسجيل دخول أو صلاحيات للمشاركين. رمز QR يُنشأ بواسطة خدمة `api.qrserver.com` عند فتح نافذة المشاركة.

## كيف تمنع النسخة الحالية التكرار؟

- نتيجة التعرّف النهائية تعالج مرة واحدة لكل فهرس، مع السماح بتكرار الكلام المقصود في عبارة جديدة.
- النص المؤقت يتغير في نفس السطر ويظل صامتاً. الجملة المعتمدة تُقرأ مرة واحدة وتُحفظ مرة واحدة.
- لكل مقطع معرّف ورقم مراجعة. النتائج المتأخرة وإعادة إرسال النتيجة النهائية لا تنشئ سطوراً جديدة.
- طلبات الجمل تبدأ مباشرة وتُعرض وتُنطق حسب ترتيب الكلام، حتى لو وصل الرد الثاني قبل الأول.
- إيقاف الاستماع يلغي أثر الترجمات المعلقة ويوقف طابور الصوت. مسح الشاشة يلغي نتائج العرض المعلقة.
- الخادم يبث للمشاركين الآخرين فقط، ولا يعيد النص إلى المرسل.
- مراقب تسميات الإضافة يستبعد واجهته والعناصر المتداخلة، وينتظر استقرار التسميات قبل ترجمتها. تتوقف مراقبة التسميات عند استخدام المايك أو استقبال بث الاستوديو.

النطق بعد اعتماد العبارة مقصود: قراءة مسودات التعرف المتغيرة كانت تعيد الكلمات وتنتج ترجمة ناقصة أو بترتيب خاطئ. زمن الاستجابة يعتمد على توقفات المتحدث والتعرف والشبكة والمزوّد؛ لا توجد ضمانة لزمن ثابت.

## المحركات وحدود التشغيل

- `auto`: يستخدم Gemini عند توفر مفتاح، وإلا يستخدم المحرك الفوري. يتحول للمحرك الاحتياطي عند فشل Gemini.
- `gemini`: يحاول Gemini، ويتحول للمحرك الفوري عند غياب المفتاح أو فشل الطلب.
- `instant`: محرك خارجي بدون مفتاح، مع مسارات احتياطية. توفر هذه الخدمات وحصصها ليسا مضمونين.

الترجمة والتعرف الشبكي يحتاجان اتصالاً بالإنترنت. نسخة PWA تحفظ ملفات الواجهة لتسهيل إعادة فتحها، وليست مترجماً يعمل دون إنترنت. فشل الخدمات يظهر كخطأ بدلاً من تقديم النص الأصلي على أنه ترجمة عربية، ولا تُحفظ الاستجابة الفاشلة في الكاش.

التقاط الصوت في التطبيق يعتمد على ميكروفون المتصفح، ولا يلتقط صوت Zoom Desktop أو صوت النظام مباشرة. يمكن للمايك التقاط صوت مكبرات الاجتماع. التحكم بصوت النظام يحتاج إعداد إدخال مناسب في النظام؛ اختيار جهاز عبر `getUserMedia` وحده لا يوجّه `SpeechRecognition`، لذلك تعرض صفحة الاستوديو الميكروفون الافتراضي فقط. توفر التعرف والأصوات العربية يختلف حسب الجهاز والمتصفح. على الهاتف افتح الموقع عبر HTTPS؛ عنوان localhost مخصص للاختبار المحلي.

يرسل النص إلى مزوّد الترجمة المستخدم. مفتاح Gemini الذي يدخله المستخدم يُحفظ في تخزين المتصفح كما في النسخة السابقة؛ يفضّل ضبطه في بيئة الخادم عند النشر على جهاز مشترك. ذاكرة كاش الخادم لا تُستخدم لطلبات المفاتيح الشخصية.

## إضافة Chrome

من `chrome://extensions/` فعّل Developer mode، ثم اختر Load unpacked وحدد مجلد `extension`. بعد تحديث الملفات أعد تحميل الإضافة وحدّث تبويب الاجتماع. يمكن استخدام تسميات YouTube أو Zoom Web أو Meet، أو ميكروفون الاستوديو. دعم محددات التسميات يحتاج تحققاً على المنصات الفعلية عند تغيّر واجهاتها.

## الفحص

```bash
npm test
npm run check
```

الاختبارات تستخدم أحداث تعرف وواجهات صوت وشبكات محاكاة، وتشمل التكرار، ترتيب الاستجابات، المسودات المتأخرة، الإيقاف، طابور الصوت، الغرف، الإضافة وفشل المزود. فحص syntax يغطي جميع ملفات JavaScript؛ لا توجد خطوة build أو TypeScript في هذا المشروع.

بعد تشغيل الخادم يمكن فحص HTTP وWebSocket ومزوّد الترجمة المجاني فعلياً:

```bash
TURJUMAN_TEST_URL=http://localhost:3000 node scripts/smoke.js
```

يستخدم هذا الفحص غرفة تجريبية وجملة عامة. لم يُتحقق هنا من Gemini بمفتاح فعلي، أو جودة صوت المايك والسماعات في اجتماع حقيقي، أو الإضافة المثبتة على Zoom/Meet/YouTube، أو النشر الخارجي.

## النشر

يتوفر `Dockerfile` و`render.yaml`. شغّل التطبيق خلف HTTPS وفعّل ترقية اتصالات WebSocket في الوكيل. حالة الغرف والكاش في ذاكرة عملية الخادم؛ التوسع إلى عدة عمليات يحتاج توجيه المشاركين إلى نفس العملية أو خدمة بث مشتركة. لا توجد قاعدة بيانات أو migrations. حدّث الصفحة أو أغلق نسخة PWA وافتحها لتحميل ملفات الواجهة الجديدة، وأعد تشغيل الخادم لتطبيق تعديلاته. للتراجع استخدم نسخة الملفات السابقة وأعد تشغيل الخدمة.
