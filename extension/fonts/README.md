# IBM Plex fonts

Unmodified WOFF2 files from [IBM/plex](https://github.com/IBM/plex/tree/48e8676114c04f29033b4b53da4ec579f8846297).

Includes IBM Plex Sans Arabic and IBM Plex Sans in weights 400, 500, 600 and 700. Licensed under the included SIL Open Font License. The public app and standalone extension each package these files so neither requires a font CDN.
